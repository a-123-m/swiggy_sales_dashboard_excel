# Swiggy Sales Dashboard - Excel

## Project Overview

The Swiggy Sales Dashboard is an interactive Excel dashboard designed to analyze food delivery sales performance and customer satisfaction metrics. The dashboard transforms raw sales data into meaningful insights through KPI tracking and visualizations, helping users understand business performance and customer behavior.

## Objective

The primary objective of this project is to monitor and analyze key business metrics related to food delivery operations, enabling data-driven decision-making through clear and interactive visualizations.

## Key Performance Indicators (KPIs)

* **Total Sales** – Overall revenue generated from food orders
* **Total Orders** – Total number of customer orders received
* **Average Order Value (AOV)** – Average revenue earned per order
* **Average Rating** – Average customer satisfaction rating
* **Rating Count** – Total number of customer reviews and ratings

## Dashboard Features

* Regional Sales Analysis
Filled Map visualization showing sales distribution across Indian states.

* Monthly Sales Trend
Line chart displaying month-wise sales performance.

* Daily Sales Analysis
Line chart showing sales trends across days of the week.

* Food Type Analysis
Doughnut chart comparing sales contribution from Veg and Non-Veg categories.

* Top 10 Restaurants Performance
Treemap visualization highlighting top-performing restaurants based on sales.

* Top 5 Cities Analysis
Bar chart showing cities generating the highest sales revenue.

* Interactive table displaying sales, average ratings, and order counts by quarter.

* Interactive Slicers - Month Filter, Food Type Filter, State Filter, Category Filter

* Dynamic Dashboard Interactivity
All visualizations update dynamically based on selected filters and slicers.
